# CookbookApp

Prosta aplikacja z przepisami kulinarnymi, napisana w Kotlinie z interfejsem opartym na XML i komponentach AndroidX. Umożliwia przeglądanie przepisów, wyświetlanie składników i instrukcji przygotowania oraz ocenianie potraw.

## Uruchomienie

1. Otwórz folder projektu w Android Studio.
2. Poczekaj na zakończenie synchronizacji Gradle.
3. Wybierz emulator lub podłączone urządzenie.
4. Kliknij przycisk **Run ▶** dla konfiguracji **app**.
